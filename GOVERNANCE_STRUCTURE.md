## 🎯 Overview

SustainChain operates at the intersection of multiple regulatory frameworks:

```
SUSTAINABILITY CHAIN = Multi-layer Regulatory Compliance

Layer 1 (India):        MPEDA ← → CMFRI ← → INCOIS
                          ↓
Layer 2 (International): FAO Global Record (IUU check)
                          ↓
Layer 3 (Destination):   EU / USA / UK / Australia
                          ↓
Layer 4 (Ocean Data):    ARGO Floats (Real-time context)

SustainChain = Automated Navigator Through This Complexity ✓
```

## 🇮🇳 Indian Domestic Authorities

### **1. Ministry of Earth Sciences (MoES)**

**Role:** Ocean monitoring, climate research, disaster warning

#### **INCOIS - Indian National Centre for Ocean Information Services**

```
📊 ARGO Float Network
├─ Coverage: 400+ profiling floats in Indian Ocean
├─ Data Collection:
│  ├─ Temperature profiles (0-2000m depth)
│  ├─ Salinity measurements
│  ├─ Oxygen levels (critical for fish habitat)
│  └─ Nutrient data
├─ Update Frequency: Every 10 days per float
├─ Data Format: NetCDF, CSV
├─ Access: Public API (Argovis)
├─ Relevance to SustainChain:
│  └─ Provides ocean health context for scoring
│
🌡️ Ocean Monitoring Services
├─ Sea Surface Temperature (SST) analysis
├─ Chlorophyll concentration mapping (productivity)
├─ Upwelling zone identification (fish concentration)
├─ Oxygen Minimum Zone (OMZ) tracking
├─ Thermal stratification analysis
└─ Seasonal advisory system
│
⚠️ Disaster Warning System
├─ Cyclone tracking (affects fishing operations)
├─ Storm surge prediction
├─ Coastal flooding alerts
└─ Impact: Determines fishing zone safety
```

**Integration with SustainChain:**
- ✅ Real-time ocean data feeds into scoring context
- ✅ Temperature/salinity inform stock health assessment
- ✅ Seasonal alerts can trigger monsoon ban enforcement

└─ SustainChain Pillar: IUU Compliance (25 points)

├─ East Coast (Bay of Bengal): April 15 - June 14

├─ Penalty: License suspension + fines
└─ SustainChain Pillar: Monsoon Compliance (15 points)

├─ Issues export permits
├─ Verifies documentation completeness
├─ Coordinates with destination countries

🤝 International Coordination
├─ EU CATCH system liaison
├─ FDA prior notification coordination
├─ UK FSA registration management

├─ FAO communication

#### **NOAA - National Oceanic & Atmospheric Administration**

```
📍 SIMP - Seafood Import Monitoring Program
├─ Coverage: 14 high-risk species, 400+ exporters
├─ Documentation Requirements:
│  ├─ Electronic submission (10 days before arrival)
│  ├─ Vessel authorization certificate
│  ├─ Catch area verification (FAO zone code)
│  ├─ Landing area verification (exact port/date)
│  ├─ Transshipment documentation (if applicable)
│  └─ Catch date confirmation
│
├─ India-Specific Requirements:
│  ├─ Exporter facility registration (NOAA database)
│  ├─ Vessel registration with Indian authorities
│  ├─ Catch area in Indian EEZ (or high seas, if applicable)
│  ├─ Landing in Indian port (documented)
│  └─ MPEDA export clearance
│
📋 Pre-Landing Electronic Documentation (PED)
├─ Submission deadline: 10 days before arrival
├─ Format: CTR (Catch Trade Record) form (electronic)
├─ Contents:
│  ├─ Exporter & importer details
│  ├─ Catch date & location (latitude/longitude)
│  ├─ Species (scientific + common name)
│  ├─ Quantity & product form (fresh/frozen/processed)
│  ├─ Vessel information (name, IMO, flag state)
│  └─ Landing date & port
│
├─ Processing:
│  ├─ NOAA system checks against vessel authorization
│  ├─ Catch area verification (zone legality)
│  ├─ Landing port cross-reference
│  ├─ Historical pattern analysis
│  └─ Risk assessment (approved/rejected/conditional entry)
│
├─ Entry Port Options (for Indian exports):
│  ├─ Port of Los Angeles (largest)
│  ├─ Port of Miami (southeastern US)
│  ├─ Port of New York (northeastern US)
│  └─ Port of Seattle (Pacific northwest)
│
└─ Enforcement:
   ├─ Detention authority (can hold shipment)
   ├─ Port state inspection (physical inspection)
   ├─ Rejection authority (refuse entry)
   └─ Penalties: Fines up to $10,000+ per violation

🤝 MSC (Marine Stewardship Council) Partnership
├─ Accepts MSC-certified seafood (fast-track approval)
├─ Premium market access for certified products
└─ Sustainability claim verification

🚫 Fisheries Enforcement Division
├─ Port State Control Inspection Authority
├─ Right to inspect foreign vessels (in US ports)
├─ Authority to detain IUU vessels
├─ Cooperation with ICE (Immigration & Customs Enforcement)
└─ Penalty Authority: Fines $1M+ for IUU violations
```

**SustainChain Integration:**
- ✅ SIMP requirement check (Pillar 5: Market Compliance)

#### **FDA - Food & Drug Administration**

```
🔬 HACCP Compliance (Seafood)
├─ 21 CFR Part 11 - Electronic Records Rule
│  ├─ Digitally signed documents acceptable
│  ├─ Record retention (2 years minimum)
│  └─ Audit trail requirement
│
├─ 21 CFR Part 110 - Seafood Processing Regulation
│  ├─ Facility design & construction standards
│  ├─ Equipment maintenance requirements
│  ├─ Personnel hygiene standards
│  ├─ Sanitation requirements
│  ├─ Maintenance of equipment
│  └─ Corrective action procedures
│
└─ HACCP Principles (7 steps)
   ├─ Step 1: Hazard Analysis (biological, chemical, physical)
   ├─ Step 2: Identify Critical Control Points (CCPs)
   ├─ Step 3: Establish preventive measures
   ├─ Step 4: Establish monitoring procedures
   ├─ Step 5: Establish corrective actions
   ├─ Step 6: Establish verification procedures
   └─ Step 7: Establish record-keeping

📋 Food Safety Modernization Act (FSMA)
├─ Foreign Supplier Verification Program (FSVP)
│  ├─ Importer must verify supplier compliance
│  ├─ Facility audit or testing required (annual)
│  ├─ Hazard analysis per supplier
│  ├─ Documentation & records (2 years)
│  └─ Corrective action plan
│
├─ Traceability Rule (FDA Food Traceability Rule - Jan 20, 2026)
│  ├─ One-step-forward, one-step-back traceability
│  ├─ Record retention (2 years minimum)
│  ├─ Product identifier & lot code required
│  ├─ Transaction date documentation
│  ├─ Location/contact information tracking
│  └─ Rapid recall capability (in case of outbreak)
│
└─ Preventive Controls (for seafood)
   ├─ Food safety plan development
   ├─ Process validation (cooking, thermal processing)
   ├─ Supplier verification & controls
   ├─ Allergen management
   └─ Recall readiness demonstration

📬 Prior Notification System
├─ Requirement: Notify FDA 72 hours before arrival
├─ Format: CTR (Catch Trade Record) form or FDA OASIS
├─ Contents:
│  ├─ Product details (name, form, quantity)
│  ├─ Shipper & consignee information
│  ├─ Vessel/vehicle identification
│  ├─ Entry port (US destination)
│  └─ Health certificate (if required)
│
├─ Processing:
│  ├─ FDA system checks against import alert list
│  ├─ Risk assessment (approved/conditional/import alert)
│  ├─ Detention authority (can hold without approval)
│  └─ Physical inspection possible (randomly or targeted)
│
└─ Rejection Authority
   ├─ Can refuse entry if documentation incomplete
   ├─ Can detain for testing
   ├─ Can refuse if failed tests
   └─ No force entry until approval

🚨 Import Alert System
├─ Maintains list of non-compliant exporters/countries
├─ India facilities flagged for past violations
├─ Automatic detention on entry (unless removed from alert)
├─ Alert removal requires demonstration of compliance
└─ Public notification available online

🧪 Testing Requirements (Mandatory)
├─ Antibiotic Residues
│  ├─ Acceptable limits: <10 ppb (parts per billion)
│  ├─ Tested species: Shrimp, fish (aquaculture & wild)
│  ├─ Test methods: LC-MS/MS or equivalent
│  └─ Sampling: Random or targeted
│
├─ Pesticide Screening
│  ├─ Common pesticides (DDT, endrin, etc.)
│  ├─ Limits per pesticide specified
│  ├─ Detected residues = detention/rejection
│  └─ Frequency: Risk-based sampling
│
├─ Heavy Metal Testing
│  ├─ Cadmium (Cd) - limit: 0.1 ppm
│  ├─ Lead (Pb) - limit: 0.1 ppm
│  ├─ Mercury (Hg) - limit: 1.0 ppm (fish), 0.5 ppm (crustaceans)
│  └─ Sampling: Quarterly or event-based
│
└─ Histamine Levels (Scombroid Fish)
   ├─ Limit: 100 ppm (ppb in some cases)
   ├─ Applies to: Tuna, mackerel, sardines, anchovies
   ├─ Testing: All shipments typically tested
   └─ Indicates: Improper temperature control/storage

📍 Port of Entry Verification
├─ Inspection type: Documentary or physical
├─ Inspection authority: FDA or CBP (Customs)
├─ Physical inspection: Lab analysis or sensory evaluation
├─ Approval timeline: Same-day to 5+ days (if testing)
└─ Rejection notification: Written refusal with reason
```

**SustainChain Integration:**
- ✅ SIMP requirement verification (vessel, catch area, landing)
- ✅ Prior notification deadline reminder (72 hours)
- ✅ FDA testing expectation flagging
- ✅ Import alert status check
